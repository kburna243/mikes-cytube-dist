Characters: 4 columns x 2 rows; first row four zombies; second row two living civilians and two poses of the same doorman boss. UI: 4 columns x 3 rows. Inspect actual image bounds and use individual frame rectangles; spacing is not perfectly uniform. Preserve existing alpha transparency in characters-atlas.png and ui-atlas.png.
